# INSTRUCCIONES PARA RESETEAR CONTRASENA DE POSTGRESQL
# =====================================================

# 1. Abre PowerShell COMO ADMINISTRADOR (clic derecho > Ejecutar como administrador)

# 2. Ejecuta este comando para editar el archivo de configuracion:
notepad "C:\Program Files\PostgreSQL\16\data\pg_hba.conf"

# 3. En el Notepad, busca estas lineas (al final del archivo):
#    host    all             all             127.0.0.1/32            scram-sha-256
#    host    all             all             ::1/128                 scram-sha-256
#
# 4. Cambia "scram-sha-256" por "trust" (temporalmente):
#    host    all             all             127.0.0.1/32            trust
#    host    all             all             ::1/128                 trust
#
# 5. Guarda (Ctrl+S) y cierra

# 6. Reinicia PostgreSQL (como ADMINISTRADOR):
Restart-Service postgresql-x64-16

# 7. Ahora puedes conectar SIN contrasena y cambiarla:
& "C:\Program Files\PostgreSQL\16\bin\psql.exe" -U postgres -c "ALTER USER postgres PASSWORD 'nueva_contrasena';"

# 8. IMPORTANTE: Vuelve a editar pg_hba.conf y cambia "trust" de vuelta a "scram-sha-256"

# 9. Reinicia PostgreSQL de nuevo:
Restart-Service postgresql-x64-16

# 10. Ahora usa tu nueva contrasena:
$env:PGPASSWORD = "nueva_contrasena"
.\test_setup.ps1
